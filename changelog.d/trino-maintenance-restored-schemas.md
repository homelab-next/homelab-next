`trino` role: a new `trino_maintenance_safe_schemas` list (empty by default) lets the operator pre-clear fresh namespaces; the maintenance timer arms without `trino_maintenance_acknowledged_restore` when `trino_maintenance_schemas` is a flat literal list and every entry is in the safe set. A mixed lake whose fresh namespace (for example `soc.*`) is safe to maintain now can be armed while the restored namespaces stay gated. Pre-existing single-gate behaviour (the ack is required) is unchanged for an empty safe list. `lab-checks` role: two read-only lake-catalog REST probes, `lake-table-fresh` (the table's `last-updated-ms` is within a window) and `lake-table-stats` (the current snapshot has a `.stats` entry in `metadata.statistics`), for per-table freshness/gap and missing-stats criteria; the base URL is the prefix up to (not including) `/namespaces`, so a reference-catalog implementation (`/v1`) and a named-warehouse implementation (`/catalog/v1/<warehouse-id>`) both work. RCA background: an internal lake-maintenance RCA, 2026-11-17.
