`modules/searxng/` ([README](modules/searxng/README.md)): the `web-search` provider on SearXNG 2026.11.9-57ff753ad, pinned by tag and digest (`role:searxng/searxng_image` in `tools/pin_freshness.py`), with the new provisional stateless slot `web-search` (`examples/modules/slots.yml`, `cap:web-search` in `homelabnext/agent/tool_classes.yml`, the keyring regenerated). One compose_app container on a `base` VM guest, internal only (row on port 8095, health `/healthz`, no public route), egress internet. The settings are rendered from role variables and the one secret key into a 0600 file: the default engine set, JSON and HTML formats (JSON is what the consumers call), the image proxy on, the limiter off, a private instance, safe search 0, optional disabled engines. Its health hook fails on a JSON search that returns no results unless `searxng_health_require_results` is false. Stateless: no export, backup or restore; the upgrade refuses a target not pinned by tag and digest. Includes the read-only slot probe `homelabnext/conform/adapters/web_search.py`. Pinned by `tests/modules/test_web_search_module.py` and `tests/roles/test_web_search_role.py`.
