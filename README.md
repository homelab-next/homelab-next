# HomelabNext

What a homelab grows into after the first lab and the question "what can I do next?":
a modular, swappable security-and-AI platform where every capability sits behind a
contract, so any one component can be replaced without rewriting the rest.

Status: early scaffolding. This repository is being built contract-first (schemas, a
service registry, shared libraries with fakes, a conformance harness and CI) before any
hardware-dependent parts. Nothing here is production-ready yet.
