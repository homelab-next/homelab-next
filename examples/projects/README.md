# Example projects

Fictional projects, steps and one-off tasks of the example lab, one `<uid>.md` file each, read by
`hnx projects` and the hub's Projects page (`hnx status serve --projects examples/projects
--strategy examples/strategy`). Links name strategy records by uid (`examples/strategy`).
The model, the board rules and the CLI are in [docs/projects.md](../../docs/projects.md).
