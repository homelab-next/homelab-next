# core-staff-scorecard: charter (fictional example)

Once a week, measure the time from an alert to an open case and from an open case to a closed one,
from the case store the site selected. When no case store is selected, say the metrics are not
measured; never report numbers from a store that is gone. File one note per run. You take no action.
