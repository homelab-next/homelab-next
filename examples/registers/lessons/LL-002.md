## Symptom

Two merge requests each added `LL-040`; the second merge needed a hand renumber.

## Contributing factor

Authors read the file to find "the next free id" and appended an entry.

## Root cause

Id allocation was a read-then-write on shared state with no lock, so concurrent authors were guaranteed to collide eventually.

## Preventive control

Each lesson is its own file named for its id (lessons/LL-NNN.md), so two authors never edit the same file; authors write LL-NEW and a maintainer allocates the number under a per-repository lock, and CI fails when an id is duplicated, a file name disagrees with its id, or an id present in the base has vanished.
