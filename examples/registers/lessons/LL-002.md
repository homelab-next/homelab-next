## Symptom

Two merge requests each added `LL-040`; the second merge needed a hand renumber.

## Contributing factor

Authors read the file to find "the next free id" and appended an entry.

## Root cause

Id allocation was a read-then-write on shared state with no lock, so concurrent authors were guaranteed to collide eventually.

## Preventive control

Authors commit `LL-NEW`; a maintainer step allocates the number under a per-repository lock, and CI fails when an id is duplicated or an id present in the base has vanished.
