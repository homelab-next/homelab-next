## Symptom

A guest created in March had no recovery point for five weeks.

## Contributing factor

Backup jobs list guests by hand and nobody added the new one.

## Root cause

The set of guests that exist and the set that are backed up are maintained in two places with no comparison between them.

## Open reason

The comparison needs the hypervisor API, which is not reachable from the example lab yet.
