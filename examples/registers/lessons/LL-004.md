## Method

Write each lesson or runbook as one Markdown file named for its id, with the structured fields in YAML front-matter and the prose in named sections; never append to a shared list file.

## Rationale

Concurrent authors of a single register file collide on ids and on merge hunks; one file per record leaves git nothing to merge except genuinely conflicting edits of one record.
