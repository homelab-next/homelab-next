## Purpose

Record a diagnosed problem so the next author finds it by symptom.

## Steps

1. Append an entry with id LL-NEW and fill symptom, contributing factor and root cause.
   - verify: the entry has all three fields and the root cause is not a person
2. Write the control and a verification that names a command and its expected result.
   - verify: python3 -m homelabnext.registers build exits 0
3. Commit; the hook allocates the number, then run the same commit again.
   - verify: git diff shows LL-NEW replaced by a number
