## Purpose

Record a diagnosed problem (a pitfall) or a method that works (a practice) so the next author finds it.

## Steps

1. Create examples/registers/lessons/<uid>.md under a new uid (`hnx records uid` prints one), with `uid`, `type: lesson`, `kind` and the fields its kind needs (a pitfall's Symptom, Contributing factor and Root cause sections; a practice's Method and applies_to).
   - verify: the file is named for its front-matter uid; a pitfall's root cause is not a person; a practice names what it applies to
   - from_lessons: [[01a15e4e-758c-7314-ba7d-8691599bb269]]
2. Write the control and a verification that names a command and its expected result.
   - verify: python3 -m homelabnext.registers build examples/registers build/registers exits 0
3. Have an agent check and a different agent's audit review stamped with the file's digest (hnx reviews digest <file>) when the status needs them.
   - verify: hnx registers review examples/registers lists no missing tier for the record
4. Commit the file as it is: the uid is its identity for good, so nothing is allocated or renamed at merge time, and the number it is shown with (LL 6) is computed.
   - verify: make ids-check passes (no record lost, no uid twice, every record carries its uid)
