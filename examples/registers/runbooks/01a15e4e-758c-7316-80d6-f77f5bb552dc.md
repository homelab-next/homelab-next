## Purpose

Restore a valid certificate on the reverse proxy without dropping connections.

## Steps

1. Run the renewal job in verbose mode and read its output.
   - verify: output ends with "certificate renewed" and the exit code is 0
2. Reload the proxy configuration.
   - verify: the reload command exits 0 and the proxy health endpoint returns 200
3. Connect from a client and read the new expiry date.
   - verify: openssl reports a notAfter date more than 60 days away
